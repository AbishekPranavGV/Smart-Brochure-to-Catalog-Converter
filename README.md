Smart Brochure-to-Catalog Converter (.pdf Download)

    Goal: Extract product images, technical specs, pricing tables, and descriptions from any incoming vendor/supplier brochure (.pdf) and auto-map them into your custom mini-catalog or full catalog layout templates for instant .pdf export.

    Tech Stack: Python, pdfplumber / pypdf (for PDF text/table extraction), PyMuPDF (fitz) (for high-res image extraction), LLM API (for unstructured data parsing & layout fitting), ReportLab / WeasyPrint (for PDF re-rendering and template dynamic generation).

    Key Features:

        Automated Extraction Engine: Pulls raw text, table key-values, and embedded high-resolution product photos directly from multi-page PDFs.

        AI Structuring Layer: Parses unstructured brochure data into clean JSON schemas (Product Title, Specifications, Features, Model Numbers, Pricing).

        Template Engine: Maps extracted JSON and images into branded layout templates (1-Page Mini Catalog, Multi-Page Master Catalog).

        Instant PDF Download: Compiles and serves clean, high-resolution .pdf downloads optimized for print and client sharing via WhatsApp or Email.
